## Description

Complete the "Bake Analytics" button action in `BakeAnalyticsWindow.cs`. When clicked, the tool must:

1. Validate the schema (abort with a dialog on any error)
2. Increment `schemaVersion` (semver patch bump)
3. Generate `Assets/CREAnalytics/Generated/Analytics.cs` — a typed C# accessor class with **recursively nested static classes** mirroring the full column path hierarchy
4. POST the schema (user fields + Session/ system fields) to the Firebase `/schemas/bake` endpoint
5. Mark the schema asset dirty and refresh AssetDatabase

**Depends on TASK-021 and TASK-021.1** — the nested schema editor must be fully complete before starting this task. The "Bake Analytics" button stub is replaced here.

## Files to Modify

- `packages/com.cre.analytics/Editor/BakeAnalyticsWindow.cs` — replace the bake stub with the real action

## Files to Create

- `packages/com.cre.analytics/Editor/AnalyticsCodeGenerator.cs` — code generation utility called by the bake action

## Acceptance Criteria

### Validation (abort if any fail)
- [ ] No field has an empty `columnName`
- [ ] No field has a `columnName` starting with `Session/` (case-insensitive)
- [ ] No duplicate `columnName` values exist in the schema
- [ ] `AnalyticsConfig` loads from `Resources.Load<AnalyticsConfig>("CREAnalyticsConfig")`; if null, show error dialog and abort
- [ ] `AnalyticsSecrets` loads from `Resources.Load<AnalyticsSecrets>("CREAnalyticsSecrets")`; if null, show error dialog and abort
- [ ] On any validation failure, show `EditorUtility.DisplayDialog("Bake Failed", message, "OK")` and return without making any changes

### Version bump
- [ ] `schemaVersion` is incremented as a semver patch: parse `"X.Y.Z"`, increment Z by 1. If the version string doesn't match semver, append `-baked` suffix as a fallback

### Code generation (`AnalyticsCodeGenerator.Generate(schema)`)

The generator builds the same tree structure as the editor UI (split each `columnName` on `/`, build a hierarchy of nodes) and emits **recursively nested** `public static class` blocks.

- [ ] Output path: `Assets/CREAnalytics/Generated/Analytics.cs`; create directory with `System.IO.Directory.CreateDirectory` if needed
- [ ] File starts with `// AUTO-GENERATED by CRE Analytics Bake — do not edit manually` and a schema version comment
- [ ] `using CRE.Analytics;` is at the top
- [ ] The root class is `public static class Analytics`
- [ ] Each intermediate path segment becomes a nested `public static class` inside its parent, named as PascalCase of the segment (strip non-alphanumeric characters before casing)
- [ ] Each leaf (a field with an `AnalyticsField`) becomes a `public static void Set{LeafName}({csType} value)` method inside its parent class; the body calls `CREAnalytics.Set("Full/Column/Name", value)` with the full original column path
- [ ] Leaf method name = `"Set"` + PascalCase of the last segment; strip non-alphanumeric characters before casing
- [ ] Fields with no `/` in their `columnName` ("ungrouped" fields) are placed as direct methods on the root `Analytics` class
- [ ] C# type mapping: `Int` → `int`, `Float` → `float`, `Bool` → `bool`, `String` → `string`, `Timestamp` → `string`
- [ ] Session/ system fields are **not** included in the generated class

### Firebase schema sync
- [ ] POST to `{config.baseUrl}/schemas/bake` using `System.Net.Http.HttpClient` with `.Result` (synchronous, acceptable in Editor)
- [ ] Request body includes: `projectId`, `projectKey`, `schemaVersion`, `columns` array with all user fields + the five Session/ system fields (see Relevant Data)
- [ ] `dataType` mapping: `Int`/`Float` → `"number"`, `String`/`Timestamp` → `"string"`, `Bool` → `"boolean"`
- [ ] On non-2xx: show `EditorUtility.DisplayDialog` with status code + response body; do not abort schema save or codegen
- [ ] Set `Content-Type: application/json` on the request

### Finalization
- [ ] Call `EditorUtility.SetDirty(schema)` and `AssetDatabase.SaveAssets()` after version bump
- [ ] Call `AssetDatabase.Refresh()` after writing the generated file

## Relevant Data

**POST /schemas/bake body:**
```json
{
  "projectId": "...",
  "projectKey": "...",
  "schemaVersion": "1.0.1",
  "columns": [
    { "columnName": "Tutorial/Cliques/Botao A", "dataType": "string" },
    { "columnName": "Tutorial/Cliques/Botao B", "dataType": "string" },
    { "columnName": "Tutorial/Duration", "dataType": "number" },
    { "columnName": "Session/StartedAt", "dataType": "string" },
    { "columnName": "Session/EndedAt", "dataType": "string" },
    { "columnName": "Session/Duration", "dataType": "number" },
    { "columnName": "Session/Platform", "dataType": "string" },
    { "columnName": "Session/DeviceModel", "dataType": "string" }
  ]
}
```

**Session/ system fields (always appended, never in ScriptableObject):**
| columnName | dataType |
|---|---|
| `Session/StartedAt` | `"string"` |
| `Session/EndedAt` | `"string"` |
| `Session/Duration` | `"number"` |
| `Session/Platform` | `"string"` |
| `Session/DeviceModel` | `"string"` |

**Generated file example** (schema with `Tutorial/Cliques/Botao A`: String, `Tutorial/Cliques/Botao B`: String, `Tutorial/Duration`: Float, `Score`: Int — ungrouped):

```csharp
// AUTO-GENERATED by CRE Analytics Bake — do not edit manually
// Schema version: 1.0.1
using CRE.Analytics;

public static class Analytics
{
    public static void SetScore(int value) => CREAnalytics.Set("Score", value);

    public static class Tutorial
    {
        public static void SetDuration(float value) => CREAnalytics.Set("Tutorial/Duration", value);

        public static class Cliques
        {
            public static void SetBotaoA(string value) => CREAnalytics.Set("Tutorial/Cliques/Botao A", value);
            public static void SetBotaoB(string value) => CREAnalytics.Set("Tutorial/Cliques/Botao B", value);
        }
    }
}
```

**JSON serialization for the HTTP POST body:**
```csharp
var body = new { projectId = ..., projectKey = ..., schemaVersion = ..., columns = columnsArray };
string json = System.Text.Json.JsonSerializer.Serialize(body);
var content = new System.Net.Http.StringContent(json, System.Text.Encoding.UTF8, "application/json");
var response = new System.Net.Http.HttpClient().PostAsync(url, content).Result;
```
