## Description

Complete the "Bake Analytics" button action in `BakeAnalyticsWindow.cs`. When clicked, the tool must:

1. Validate the schema (abort with a dialog on any error)
2. Increment `schemaVersion` (semver patch bump)
3. Generate `Assets/CREAnalytics/Generated/Analytics.cs` — a typed C# accessor class
4. POST the schema (user fields + Session/ system fields) to the Firebase `/schemas/bake` endpoint
5. Mark the schema asset dirty and refresh AssetDatabase

**Depends on TASK-021** — the grouped schema editor must be complete before starting this task. The "Bake Analytics" button stub added in TASK-021 is replaced here.

## Files to Modify

- `packages/com.cre.analytics/Editor/BakeAnalyticsWindow.cs` — replace the bake stub with the real action

## Files to Create

- `packages/com.cre.analytics/Editor/AnalyticsCodeGenerator.cs` — code generation utility called by the bake action

## Acceptance Criteria

### Validation (abort if any fail)
- [ ] No field has an empty `columnName`
- [ ] No field has a `columnName` starting with `Session/` (case-insensitive)
- [ ] No duplicate `columnName` values exist in the schema
- [ ] `AnalyticsConfig` loads successfully from `Resources.Load<AnalyticsConfig>("CREAnalyticsConfig")`; if null, show error dialog and abort
- [ ] `AnalyticsSecrets` loads from `Resources.Load<AnalyticsSecrets>("CREAnalyticsSecrets")`; if null, show error dialog and abort
- [ ] On any validation failure, show `EditorUtility.DisplayDialog("Bake Failed", message, "OK")` and return without making any changes

### Version bump
- [ ] `schemaVersion` is incremented as a semver patch: parse `"X.Y.Z"`, increment Z by 1, write back as `"X.Y.Z+1"`. If the version string doesn't match semver, append `-baked` suffix as a fallback

### Code generation (`AnalyticsCodeGenerator.Generate(schema)`)
- [ ] Output path: `Assets/CREAnalytics/Generated/Analytics.cs`; create `Assets/CREAnalytics/Generated/` folder if it doesn't exist using `System.IO.Directory.CreateDirectory`
- [ ] Generated file starts with `// AUTO-GENERATED by CRE Analytics Bake — do not edit manually` and a schema version comment
- [ ] One nested `public static class` per schema group name (groups derived same way as TASK-021: first path segment)
- [ ] Fields in "Other" group (no `/`) go as direct methods on the root `Analytics` class, not in a nested class
- [ ] One `public static void Set{FieldName}({csType} value)` method per field within the group; body: `CREAnalytics.Set("Full/Column/Name", value);`
- [ ] Field method name = `"Set"` + PascalCase of the short display name (part after last `/`); strip non-alphanumeric characters before casing
- [ ] Nested class name = PascalCase of the group name; strip non-alphanumeric characters
- [ ] C# type mapping: `Int` → `int`, `Float` → `float`, `Bool` → `bool`, `String` → `string`, `Timestamp` → `string`
- [ ] Session/ system fields are **not** included in the generated class (they are SDK-internal)
- [ ] `using CRE.Analytics;` is included at the top

### Firebase schema sync
- [ ] POST to `{config.baseUrl}/schemas/bake` using `System.Net.Http.HttpClient`; call `.Result` synchronously (acceptable in Editor context)
- [ ] Request body is JSON with fields: `projectId`, `projectKey`, `schemaVersion`, `columns` (array of `{ columnName, dataType }`)
- [ ] `columns` includes all user-defined schema fields **plus** the five Session/ system fields (hardcoded, see Relevant Data)
- [ ] `dataType` mapping: `Int`/`Float` → `"number"`, `String`/`Timestamp` → `"string"`, `Bool` → `"boolean"`
- [ ] On non-2xx response, show `EditorUtility.DisplayDialog` with status code and response body; do not abort schema save or codegen (bake is still locally valid)
- [ ] Set `Content-Type: application/json` on the request

### Finalization
- [ ] Call `EditorUtility.SetDirty(schema)` and `AssetDatabase.SaveAssets()` after version bump
- [ ] Call `AssetDatabase.Refresh()` after writing the generated file so Unity picks it up

## Relevant Data

**POST /schemas/bake body:**
```json
{
  "projectId": "...",
  "projectKey": "...",
  "schemaVersion": "1.0.1",
  "columns": [
    { "columnName": "Tutorial/Steps", "dataType": "number" },
    { "columnName": "Tutorial/Duration", "dataType": "number" },
    { "columnName": "Session/StartedAt", "dataType": "string" },
    { "columnName": "Session/EndedAt", "dataType": "string" },
    { "columnName": "Session/Duration", "dataType": "number" },
    { "columnName": "Session/Platform", "dataType": "string" },
    { "columnName": "Session/DeviceModel", "dataType": "string" }
  ]
}
```

**Session/ system fields (always appended to every bake payload — do not expose in schema ScriptableObject):**
| columnName | dataType |
|---|---|
| `Session/StartedAt` | `"string"` |
| `Session/EndedAt` | `"string"` |
| `Session/Duration` | `"number"` |
| `Session/Platform` | `"string"` |
| `Session/DeviceModel` | `"string"` |

**Generated file example** (schema: group "Tutorial" with Steps: Int and Duration: Float; group "Main Experience" with Duration: Float):
```csharp
// AUTO-GENERATED by CRE Analytics Bake — do not edit manually
// Schema version: 1.0.1
using CRE.Analytics;

public static class Analytics
{
    public static class Tutorial
    {
        public static void SetSteps(int value) => CREAnalytics.Set("Tutorial/Steps", value);
        public static void SetDuration(float value) => CREAnalytics.Set("Tutorial/Duration", value);
    }

    public static class MainExperience
    {
        public static void SetDuration(float value) => CREAnalytics.Set("Main Experience/Duration", value);
    }
}
```

**JSON serialization for the HTTP POST body (Editor context, no Unity serialization constraints):**
```csharp
var body = new { projectId = ..., projectKey = ..., schemaVersion = ..., columns = columnsArray };
string json = System.Text.Json.JsonSerializer.Serialize(body);
var content = new System.Net.Http.StringContent(json, System.Text.Encoding.UTF8, "application/json");
var response = new System.Net.Http.HttpClient().PostAsync(url, content).Result;
```
